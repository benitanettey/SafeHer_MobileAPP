 **SafeHer – Offline Women’s Safety Android App**

SafeHer is an offline-enabled Android mobile application designed to provide preventive safety measures against Gender-Based Violence (GBV).
The app focuses on SMS-based SOS alerts, offline location sharing, trusted contacts (Support Circle), and daily safety check-ins, ensuring reliability even in low-connectivity environments.

Key Features

One-Tap SOS Alert
Sends emergency messages via SMS to trusted contacts without internet access.

Offline Location Sharing
Shares last known GPS location using Google Maps links.

Support Circle Management
Add, edit, delete, and manage trusted contacts stored securely on the device.

Daily Check-Ins & Wellness Journal
Allows users to confirm safety or send concern messages discreetly.

Privacy & Security
PIN lock, local storage, and no cloud dependency.

**Technology Stack**

Platform: Android

Language: Java

IDE: Android Studio

Storage: SharedPreferences & SQLite

APIs: SMS Manager, Fused Location Provider
